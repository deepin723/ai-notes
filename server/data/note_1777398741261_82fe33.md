## 项目定位

ai-chat 是一款面向个人用户的多模型 AI 对话平台，用户携带自己的 API Key 进入，支持主流大语言模型切换，提供流畅的流式对话体验。

## 核心功能

- 多模型支持：gpt-4.1、claude-opus-4-6、gemini 等可配置切换
- 流式输出：SSE（Server-Sent Events）技术，响应逐字输出，无需等待
- 对话历史：同一 session 内的多轮上下文保留
- Markdown 渲染：代码块高亮、表格、列表等格式完整支持
- API Key 本地化：Key 存储在 localStorage，不上传服务器

## 技术架构

### 前端
- 框架：Vue 3 + TypeScript + Vite
- 部署：Vercel（CDN 加速，全球边缘节点）
- 端口：5173（本地开发）

### 后端
- 框架：Node.js + Express
- 部署：Railway（Docker 容器化，自动 CI/CD）
- 端口：3001
- 核心逻辑：接收前端请求，转发至 OpenAI 兼容接口，SSE 流式透传响应

## 用户流程

1. 打开应用 → 输入 API Key 与 Base URL
2. 选择对话模型
3. 输入问题 → 实时看到 AI 逐字回答
4. 多轮对话，历史保留在当前 session

## 亮点设计

- 零账号体系：用户即到即用，无注册
- 模型灵活切换：只需修改 Base URL 即可对接任意 OpenAI 兼容 API
- 流式代理：后端不缓存，直接管道转发，延迟极低
