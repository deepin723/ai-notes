## 价值投资的本质

价值投资由本杰明·格雷厄姆创立，核心思想：**以低于内在价值的价格买入股票，等待市场回归理性。**

格雷厄姆比喻：市场是一个叫"市场先生"的情绪不稳定的合伙人，每天报出不同的买卖价格。聪明的投资者只在价格低于价值时买入，不受情绪影响。

## 巴菲特的进化：买好公司而非便宜公司

格雷厄姆关注"烟蒂股"（捡便宜），巴菲特在芒格影响下进化为：**以合理价格买入优秀公司，长期持有。**

**优秀公司的标准：**
1. 持久的竞争优势（护城河）
2. 优秀且诚实的管理层
3. 高资本回报率（ROE > 15%持续）
4. 良好的现金流，不依赖持续融资

## 护城河的五种形态

| 护城河类型 | 例子 | 特征 |
|----------|------|------|
| 无形资产 | 贵州茅台、可口可乐 | 品牌溢价，消费者忠诚 |
| 转换成本 | 微软Office、Salesforce | 用户切换代价高 |
| 网络效应 | 微信、Visa | 用户越多价值越大 |
| 成本优势 | 沃尔玛、拼多多 | 规模碾压对手 |
| 有效规模 | 地方水电、管道 | 市场容量限制竞争者进入 |

## 内在价值的估算

**DCF模型（现金流折现）：**  
内在价值 = 未来所有自由现金流 / 折现率 的现值之和

简化版（芒格风格）：不要过度精确，估算是否"足够便宜"即可。"宁要模糊的正确，不要精确的错误。"

**市盈率（PE）参考：**
- PE < 15：相对低估区域
- PE 15-25：合理估值
- PE > 30：需要高增长支撑，否则高估

## 安全边际

格雷厄姆最重要的概念：**买价必须显著低于内在价值（通常要求30%-50%折扣）**，用来对抗估值误差和不确定性。

## 芒格的多元思维模型

芒格认为：需要跨学科的思维模型格栅——心理学（避免认知偏差）、统计学（概率思维）、物理学（临界点）、生物学（适应进化）等，综合判断一家公司的长期前景。

## 核心原则总结

1. 只投资自己理解的业务（能力圈）
2. 宁可等待，不强行出手
3. 集中投资，不过度分散（前10大持仓占85%以上）
4. 永远考虑下行风险
5. **持有期限=永远**（除非公司基本面恶化）
