## 项目概况

**tinyhumansai/openhuman** | Rust | 3,973 stars today | [github.com/tinyhumansai/openhuman](https://github.com/tinyhumansai/openhuman)

定位：个人 AI 超级智能体（Personal AI Super Intelligence）——一个本地优先、深度集成日常工作流的开源桌面 AI Agent。

## 核心功能

**118+ 第三方集成 + 自动拉取**：一键 OAuth 接入 Gmail、Notion、GitHub、Slack、Stripe、Calendar、Drive、Linear、Jira 等。每 20 分钟自动遍历活跃连接，把最新数据拉进记忆树——不需要你手动提问，Agent 明天早上就已经知道了你今天的上下文。

**Memory Tree + Obsidian Wiki**：本地优先知识库，所有连接的数据被 canonicalize 成 ≤3k-token Markdown 块，存入 SQLite，同时落地为 `.md` 文件——标准 Obsidian vault 格式，可以直接打开浏览和编辑。灵感来自 Karpathy 的 obsidian-wiki 工作流。

**桌面吉祥物（Mascot）**：有脸的 AI——能说话（ElevenLabs TTS + 嘴部同步）、响应周围环境、以真实参与者身份加入 Google Meet、在你停止输入后继续在后台思考。

**模型路由**：每个任务发给最合适的 LLM（推理型/快速型/视觉型），一个订阅搞定，不需要手动切换。

**内置工具集**：网络搜索、网页抓取、完整编码工具集（文件系统 + git + lint + 测试 + grep）、原生语音（STT 输入 + TTS 输出）。

## 安装方式

```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/tinyhumansai/openhuman/main/scripts/install.sh | bash
```

或直接从 [tinyhumans.ai/openhuman](https://tinyhumans.ai/openhuman) 下载 DMG/EXE。

## 我的判断

这个项目的雄心很大——不是"一个更好的 ChatGPT 客户端"，而是真正意义上的个人 AI 秘书：主动获取上下文、持续在后台思考、深度集成工作流。

3973 star/天的热度说明市场对"本地优先 AI Agent"有强烈需求——人们既想要 AI 深入了解自己，又不想把所有数据上传到云端。

**值得关注的设计选择**：记忆树同步为 Obsidian 格式——这意味着用户的 AI 记忆是可读、可编辑、可版本控制的。相比黑盒记忆（ChatGPT Memory），这种透明度是真实的技术差异化。

还在 Early Beta，粗糙边缘较多，但架构思路值得深入研究。
