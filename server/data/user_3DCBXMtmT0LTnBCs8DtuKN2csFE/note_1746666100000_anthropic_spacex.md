## 事件核心

Anthropic 与 SpaceX 达成战略合作，内容不是普通的软件 API 互调，而是**两块**：

1. **算力合作** — 具体条款未完全披露，但大概率是 SpaceX 承接 Anthropic 的部分训练/推理基础设施
2. **太空开发合作** — Claude 将被用于 SpaceX 某些业务线（猜测：火箭遥测数据分析、卫星任务规划、Starlink 运营优化）

这两家公司此前几乎没有交集，现在突然绑定，值得细看。

---

## 这合作里有几件事不那么显然

### 1. Anthropic 需要"非 AWS"的算力选项

Anthropic 过去是 AWS 深度合作伙伴（Amazon 投了 80 亿美元），大部分训练跑在 AWS。

但随着规模扩张，**单一云商锁死**的风险变得真实：
- AWS 上的 GPU 供给跟整个市场紧张，排队
- 价格谈判筹码弱
- 地缘政治风险（美国对华出口管制 → AWS 中东某些区域受限）

SpaceX 在德州正在建**自己的数据中心**（为 Starlink、xAI 服务）。如果 Anthropic 能拿到 SpaceX 自建的算力，就有了"AWS 之外的第二条腿"。

### 2. 这是 xAI 和 Anthropic "转过身来合作"的罕见信号

马斯克（SpaceX 老板）和 xAI 是 Anthropic 的竞争对手。按理说 SpaceX 会优先给 xAI 供算力。

但现在 SpaceX 愿意给 Anthropic 也供算力，说明：
- SpaceX 的算力规模已经大到能同时服务多家
- SpaceX 把自己定位成**中立基础设施提供商**，而不是 xAI 的独家金库
- 这其实也为 SpaceX 自己的数据中心业务增加一个客户

**商业逻辑**：SpaceX 的数据中心业务如果只服务 xAI 一家，商业模型太脆弱。加一个 Anthropic，多元化收入，才是可持续的基础设施生意。

### 3. "太空开发"可能只是个点缀

关于"太空开发合作"的具体内容，目前披露很少。**真正的重点我猜是算力，太空合作只是点缀包装**——让这事听起来有故事感、有头条价值。

或者，更务实地说：Claude 可能被 SpaceX 用于内部工程（写代码、做分析），这本来就是一单普通的企业客户采购。现在作为合作新闻的一部分打包出来，显得宏大。

## 我的判断

### ① AI 公司和"非云大厂"基础设施商正在形成新的联盟

过去算力供给是**三巨头垄断**（AWS / Azure / GCP）。现在出现新玩家：
- **SpaceX**（自建数据中心）
- **Oracle**（OpenAI 的主要算力供应商）
- **CoreWeave**（纯 GPU 云）
- **Lambda Labs**

这些新玩家的共同点：**不需要卖操作系统、不需要卖数据库，只卖算力**。AI 公司跟它们合作比跟云大厂合作更单纯——后者总想把你锁进它整个生态。

### ② 算力正在变成**地缘政治资产**，不再是纯商品

SpaceX 数据中心在德州。Anthropic 的 AWS 算力有全球各区域。

**有数据中心的地理分布 = 能服务的客户地理范围**。
- 你的数据中心只在美国 → 欧洲客户不信你（GDPR）
- 你的数据中心只在 AWS → 美国政府客户不完全信你（多云要求）

SpaceX 作为一个"美国战略公司"的身份，对某些客户反而是加分项。

### ③ Anthropic 的战略越来越清晰：**做美国企业客户，不争 C 端**

看 Anthropic 最近的动作：
- 推 Claude for Enterprise、Claude for Government
- 推 Financial Services 垂直（今天另一篇笔记会细讲）
- 现在跟 SpaceX 合作

**OpenAI 的打法是 B + C 通吃**（ChatGPT 消费者 + GPT Enterprise）。
**Anthropic 的打法是 B 优先，C 是副产品**。

这个选择可能才是 AI 公司分化的长期路径。

---

## 对我的启示

1. **基础设施层的创业机会远没完结**。"AI 公司"只是一层，它下面的算力层、网络层、存储层、调度层，每一层都在出新玩家。**今天想做 AI 创业，选对战场很重要——应用层已经卷到不行，但基础设施层还很荒**。

2. **观察一家 AI 公司的战略，看它的合作伙伴和定价比看它的模型更准**。模型差距最终会被抹平，但战略选择定义 5-10 年的护城河。

3. **算力会越来越政治化**。**英伟达→出口管制→替代方案**的链条是未来几年的主线。关注"美国以外的算力方案"（中国、东南亚、中东）的发展，能看到很多被低估的机会。

---

## 延伸：为什么马斯克没有要求 SpaceX 独家供 xAI

表面上看马斯克应该让 SpaceX 只服务 xAI。但他没有，原因我猜有两个：

1. **SpaceX 是上市前的独立公司**，有独立董事会和非马斯克股东。把 SpaceX 变成 xAI 的附属品会侵害其他股东利益。
2. **马斯克最近跟 Trump 关系好**，正在争取美国政府的 AI 基建订单。如果 SpaceX 被定义成"xAI 专属"，政府采购逻辑上就复杂了。保持"多元服务"的形象，方便拿政府的钱。

所以这次 Anthropic 的合作，本质上**受益于 xAI 老板的政治野心**——这就是商业世界的吊诡之处。
