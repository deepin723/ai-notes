## 核心事件

2026 年初，Warren Buffett 正式将伯克希尔哈撒韦（NYSE: BRK.A / BRK.B）CEO 职位交给 Greg Abel——结束了长达 60 年的掌舵。

Abel 上任后的首个重大个人动作：**买入 $2.35 亿的伯克希尔股票**。

## 为什么这件事重要

**这是市场信号，不只是新闻**

CEO 大手笔增持自家公司股票，是最有力的"内部人看多"信号之一。Abel 用 2.35 亿美元的个人资金告诉市场：我认为 BRK 现在的价格值得买入。

相比巴菲特执掌期间（他几乎不增持），Abel 这一举动显得格外明确。

## 伯克希尔的核心数据

巴菲特 1965-2025 执掌期间：

| 指标 | 数值 |
|------|------|
| BRK 年化回报 | 19.7% |
| S&P 500 年化回报 | 10.5% |
| $1,000 投入 BRK (1965) | → $4,850 万 (2025) |
| $1,000 投入 S&P (1965) | → $399,702 (2025) |

**核心持仓逻辑（以两个经典案例说明）**：

- **可口可乐 (KO)**：1988-1994 年以 $13 亿买入 4 亿股，从未卖出。现在市值 $320 亿，去年光分红就收到 $8.16 亿——比当年总成本的 63% 。
- **苹果 (AAPL)**：2016-2023 年投入约 $380 亿，峰值市值 $1700 亿（占 BRK 股票组合 50%）。2024-2025 年减持四分之三到 25%，锁定收益同时降低集中风险。

**企业结构**：除了公开市场股票组合（$3000 亿），BRK 还持有大量私有子公司——保险（GEICO、Gen Re）、铁路（BNSF）、工业企业（Precision Castparts）、公用事业（BHE）——这些子公司持续产生稳定现金流，支撑 BRK 的其他投资。

## Greg Abel 面临的挑战

接手一个万亿市值的企业，没有"新官上任三把火"的机会。市场会把 Abel 的每个决策与巴菲特的历史风格对比——他的每次增仓、减仓都会被放大解读。

$2.35 亿的增持是在说：**"我不需要改变什么，我相信这个体系的价值。"** 这是稳定信心、而非激进转型的姿态。

## 我的判断

对投资者的实际意义：

**BRK 是"美国经济的指数基金"** ——持有 BRK.B 等价于持有一个分散化的美国经济组合，且背后有专业的资本配置团队，管理费为零。

Abel 买入本身不是"短线催化剂"，而是长期价值信号。如果你对 BRK 有持仓意向，Abel 的增持是一个正面的基本面确认。

**对比参照**：BRK.B 当前估值约 1.6x P/B，历史上跌破 1.2x P/B 是公认的低估区间（巴菲特本人也曾在这个区间主动回购股票）。Abel 的买入价格意味着他认为当前估值合理。

**实际建议**：BRK.B 是相对稳健的美股持仓选择，适合不想自己选股但又想比纯指数基金多一点"主动配置"的投资者。Abel 的过渡是平稳的，无需因"换帅"而悲观。
