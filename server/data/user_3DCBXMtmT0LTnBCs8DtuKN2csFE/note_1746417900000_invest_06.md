## A股与美股的本质差异

| 特征 | A股 | 美股 |
|------|-----|------|
| 投资者结构 | 散户为主（约55%成交量）| 机构为主（>70%）|
| 涨跌停机制 | ±10%（ST±5%）| 无限制 |
| T+1限制 | 买入次日才能卖出 | T+0当日可卖 |
| 退市机制 | 较宽松 | 严格 |
| 政策影响 | 极强 | 中等 |
| 估值体系 | 波动大，情绪化 | 相对理性 |
| IPO制度 | 注册制（转变中）| 注册制 |

## A股的"政策市"特征

A股受政策影响远超基本面驱动：
- 货币政策（降准降息）→ 资金宽松 → 牛市
- 监管收紧 → 某行业集体暴跌
- 国家队入市 → 托底指数
- 两会政策方向 → 相关板块轮动

**实用策略：** 关注政策方向先于研究个股基本面。"不要与政策对着干。"

## A股的周期规律

历史上A股约4-5年一个完整牛熊周期：
- 2005-2007：大牛市（上证从1000到6124）
- 2008：大熊市（跌70%）
- 2009-2010：反弹牛
- 2013-2015：杠杆牛（上证5178后崩盘）
- 2016-2018：价值白马行情
- 2019-2021：核心资产/赛道股大牛
- 2022-2023：熊市调整
- 2024+：政策刺激修复

**结论：** 熊市末期（市场极度悲观）是布局时机，牛市中段是享受，牛市顶部是离场。

## 散户高胜率策略

**策略一：宽基指数+估值定投**
不选股，定投沪深300/中证500，PE低于历史均值时加大买入，PE高于历史均值时减少买入。历史回测年化约10-12%。

**策略二：行业轮动**
A股行业轮动特征明显：消费→科技→周期→金融，跟随景气度切换。适合有时间研究的投资者。

**策略三：北向资金跟踪**
北向资金（外资）被认为是"聪明钱"，持续流入的股票往往有基本面支撑。

## 常见A股陷阱

**融资融券（杠杆）：** 放大收益也放大亏损。散户使用杠杆的胜率极低，切忌加杠杆。

**跟风打板（追涨停）：** 短线博弈，需要专业技能和快速执行，普通散户大概率亏损。

**消息炒作：** "内部消息"往往是被人利用的出货工具。等你听到消息，主力已经出货完毕。

**ST股/垃圾股：** 低价不代表便宜，退市风险极高。
