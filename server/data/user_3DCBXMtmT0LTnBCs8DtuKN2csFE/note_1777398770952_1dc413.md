## 项目定位

Deepin Image 是一款基于 gpt-image-2（gpt-5.4 模型）的 AI 图像生成平台，定位是让非技术用户也能轻松使用顶级图像生成能力，用户携带自己的 API Key，所有调用走用户自己的额度。

## 核心功能

- 文字生图：中文描述 → 高质量图像
- 参考图上传：支持图生图，用户上传参考图影响生成风格
- 尺寸选择：方形(1024×1024)、横版(1536×1024)、竖版(1024×1536)
- 风格快捷标签：电影感、赛博朋克、水彩插画、胶片质感等 8 种预设
- 提示词优化：一键调用 LLM 将中文简描扩展为专业英文 prompt
- 后台任务队列：生成不阻塞 UI，可边等待边浏览历史
- 历史记录：当前 session 内生成的图片可回溯查看
- 下载 / 复制：图片支持本地下载和复制到剪贴板

## 技术架构

### 前端
- 框架：Vue 3 + TypeScript + Vite
- 部署：Vercel，域名 dp-gpt-image-2.vercel.app
- 关键设计：任务队列（tasks: Task[]），non-reactive isProcessing flag，floating task panel

### 后端
- 框架：Node.js + Express
- 部署：Railway，域名 dp-gpt-image-2-production.up.railway.app
- 端口：3003
- 接口一：POST /api/generate-image → 调 OpenAI /responses 接口，SSE 流式解析，提取 image_generation_call base64
- 接口二：POST /api/enhance-prompt → 调 /chat/completions，扩展提示词

## 关键技术难点

### Vercel 60s 超时问题
图像生成需要 2-5 分钟，Vercel Serverless Function 只有 60s 超时。解决方案：前端直接请求 Railway 后端，绕过 Vercel 代理限制。

### SSE 流式读取
gpt-image-2 通过 /responses 接口返回 SSE 流，需要逐行解析 data: {...} 事件，找到 type=response.output_item.done 且 item.type=image_generation_call 时立即返回结果。

### 后台任务队列
用 processNext() 递归函数实现非阻塞任务队列，每个任务独立计时器（进度条 + 消息轮换），任务完成后自动触发下一个。

## 用户流程

1. 输入 API Key → 进入生成界面
2. 选择尺寸、添加风格标签、输入描述（可选优化描述）
3. 点击「生成图片」→ 任务进入队列，UI 可继续操作
4. 浮动任务面板显示进度 → 完成后点击查看
5. 下载或复制图片
