## 项目工作流

FaceSwap使用深度学习识别并替换图片或视频中的人脸，支持Windows、Linux和macOS。完整流程分为四步：收集已获许可的素材，Extract检测并对齐人脸，Train训练两组身份之间的转换模型，Convert把模型应用到目标图像。GUI只是这套管线的可视化入口，底层仍能通过命令行精细控制。

现代CUDA GPU能获得更好的训练速度，Linux下也支持部分AMD GPU的ROCm。项目建议复用相近脸型的已有模型做迁移训练，以减少从零训练所需的数据和时间。

## 为什么README花大量篇幅谈伦理

早期“deepfake”代码把原本局限在论文和实验室的技术变成普通人可以下载、试验的工具，也迅速被用于未经同意的色情与欺骗内容。FaceSwap团队因此明确声明：不应用于不当内容、未经同意的换脸、隐藏合成事实或其他非法用途，并把教育、电影、实验和评论视为合理场景。

这不是附属声明，而是产品风险的一部分。生成结果越逼真，素材授权、输出标识和传播控制越重要。

## 我的判断

开源声明能够建立社区规范，却无法阻止下游删除水印或绕过限制。真正降低风险需要技术与流程共同作用：保留素材授权记录、默认添加可识别标记、限制批量处理陌生人脸，并支持内容溯源。

另一方面，完全封闭技术也不会消除滥用，只会让检测、教育和合规研究更困难。更可行的方向是让合法用途可审计，让未经同意的使用成本更高。

## 对我的启示

任何涉及真人身份的生成项目，在训练前都要回答“素材是否获得许可”，发布前要回答“观众能否知道这是合成内容”。模型效果不是唯一验收标准，同意与可追溯性同样是功能。
