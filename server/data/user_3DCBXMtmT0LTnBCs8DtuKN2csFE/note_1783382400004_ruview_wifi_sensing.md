## 项目概览

**仓库**：ruvnet/RuView  
**今日 Star**：1,122  
**技术栈**：Rust  
**定位**：基于 WiFi CSI（信道状态信息）的空间智能平台，无摄像头，可透墙感知

## 核心能力

用约 9 美元一颗的 ESP32 WiFi 模块，通过分析 WiFi 信号在空间中的传播变化（CSI）实现：

- **人员检测**：有人 / 没人
- **人数统计**：多少人在房间里
- **生命体征监测**：呼吸频率、心率（穿过墙壁）
- **活动识别**：走路、坐着、睡觉等状态
- **睡眠质量分类**：轻睡、深睡、REM

感知范围：ESP32 节点组成 mesh 网络，每个节点覆盖一个区域，多节点可以覆盖整栋建筑。

## 技术原理

WiFi 信号在传播过程中会被人体反射和吸收，造成信道状态（CSI）的细微变化。人的呼吸和心跳会以特定频率调制这些变化（呼吸约 0.2-0.5Hz，心跳约 1-2Hz）。

RuView 用**脉冲神经网络（Spiking Neural Networks）**处理 CSI 数据流：
- 30秒内完成初始校准
- 无需大量训练数据
- 模型在边缘设备上运行，数据不出本地网络

生成加密签名的检测结果，可以验证数据来源（针对伪造传感器数据的攻击）。

## 集成支持

原生支持智能家居主流协议：Home Assistant、Apple Home、Google Home、Alexa、Matter。可以直接作为传感器接入现有智能家居系统。

## 我的判断

这个技术的能力范围让人觉得"比想象的更强"，也"比想象的更令人不安"。

**有价值的应用场景**：
- 老人独居监护（呼吸停止立即报警，不需要穿戴设备）
- 智能家居能耗优化（没人的房间自动关灯/空调）
- 疗养院/医院非侵入式生命体征监测

**令人担忧的应用场景**：
- 房东在出租屋内监控租客（穿墙感知，无需明显摄像头）
- 商业空间对客户的密度和行为分析（无感知情况下）
- 执法机构透墙侦察（廉价、易部署）

这个技术的特点是**感知能力强但存在感极低**——WiFi 信号无处不在，ESP32 模块体积微小，非常难以被发现。这与摄像头（视觉可见）或运动传感器（通常需要明显安装位置）有本质区别。

**实际可用的结论**：如果你有老人独居监护需求，这是目前成本最低、侵入性最小的方案之一。但如果你在出租或使用他人空间，意识到这类技术的存在是有必要的——WiFi 信号泄露的信息远不止"有没有设备连接"。
