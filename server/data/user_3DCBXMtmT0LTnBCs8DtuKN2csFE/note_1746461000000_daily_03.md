## 今日主题线：Agent 工具层进入爆发期

今天 Top 10 里有一半以上项目都直接和 AI Agent 相关，而且方向很聚焦——**不是在造新 Agent，是在解决 Agent 的基础设施问题**：

- 怎么让多个 Agent 协调工作（ruflo）
- 怎么给 Agent 喂实时鲜活的数据（cocoindex）
- 怎么不让 Agent 把 context window 用爆（context-mode）
- 怎么给 Agent 提供更多预设技能（agency-agents）

这个格局和 2015 年前后的 Web 框架时代很像——React/Vue 出来之后，大量周边工具（状态管理、路由、工具链）集中涌现。现在 Claude Code / GPT-4 这类 "核心 Agent" 已经成熟了，工具层正在被快速填充。

---

## 另一条线：开源替代昂贵 SaaS

docuseal（DocuSign 替代品）今天涨了 927 星。这类项目的逻辑很简单：**找一个用户量大但价格贵的 SaaS，做一个开源+可私有化部署的版本**。

DocuSign 企业版一年要几千美元，docuseal 自托管免费。技术团队的选择越来越明确：自己部署，数据不出境，成本可控。

这个趋势会持续。下一个可能被替代的 SaaS 候选清单：Notion（已有 Obsidian/AppFlowy）、Figma（已有 Penpot）、Jira（已有 Linear/Plane）……
