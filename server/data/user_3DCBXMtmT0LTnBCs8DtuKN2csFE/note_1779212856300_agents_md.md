## 核心结论

`AGENTS.md` 是写给 AI 编程助手看的项目规范文件——5 分钟写一份，AI 就知道你的规矩，代码规范率从 60% 直接跳到 95%。

## 类比理解

| 文件 | 给谁看 | 管什么 |
|------|--------|--------|
| `.eslintrc` | ESLint | 代码风格 |
| `.prettierrc` | Prettier | 格式化规则 |
| `tsconfig.json` | TypeScript | 类型检查 |
| **`AGENTS.md`** | **AI 编程助手** | **项目规范、目录结构、编码约定、禁止事项** |

没有 AGENTS.md，AI 是个能力强但不知道团队规矩的新人。

## 有无 AGENTS.md 的真实差距

**没有时，AI 写一个复制按钮组件：**
```tsx
export default function CopyBtn({ text }: any) {
  return (
    <button style={{ color: 'blue', padding: '4px 8px' }}
      onClick={() => navigator.clipboard.writeText(text)}>
      Copy
    </button>
  )
}
```
问题清单：`any` 类型、内联样式、命名不规范（应 `CopyButton`）、没用 antd message、文件没放对目录。

**有 AGENTS.md 后，AI 自动生成规范代码**：TypeScript 强类型 + CSS Modules + antd + 正确命名 + 正确目录——无需任何额外提示。

## AGENTS.md 的六大章节

```markdown
# AGENTS.md

## 1. 技术栈声明
本项目为 React 19 + TypeScript；包管理器 yarn；Node >= 22.12.0

## 2. 目录结构
src/components/  # 通用组件（PascalCase）
src/pages/       # 页面组件
src/hooks/       # 自定义 Hooks
src/services/    # API 请求封装

## 3. 编码规范
- 使用 interface 定义 Props
- Never 使用 any 类型
- Never 使用内联样式

## 4. 构建命令
yarn serve    # 开发服务器
yarn build    # 生产构建

## 5. Never 规则
- Never edit src/.umi/
- Never edit dist/

## 6. 约定与协作
- 组件命名 PascalCase，文件名 index.tsx
```

## 我的判断

这是一个极低成本、极高回报的实践——5 分钟写，所有后续 AI 生成的代码都自动对齐团队规范。

**更深层的价值**：AGENTS.md 其实是在强迫团队把"隐性规范"显性化。很多团队的规范只存在于老员工的脑子里，新人需要靠代码 review 才能学到。写 AGENTS.md 的过程本身就是在沉淀知识。

**实际可用的结论**：在所有用 AI 辅助开发的项目里，都应该有一份 AGENTS.md。如果你用 Claude Code，它会自动读取 `CLAUDE.md`（Anthropic 的同类规范文件），逻辑完全一样。今天就可以给当前项目写一份。
