## 核心事件

5 月 17 日，中国电信、中国移动、中国联通同天推出 Token 套餐服务：

- **电信个人版**：9.9 元/月 1000 万 Token；49.9 元/月 8000 万 Token
- **电信企业版**：39.9 元/月 1500 万 Token；299.9 元/月 1.5 亿 Token
- **移动上海**：1 元购 40 万 Token，支持话费支付，多模型通用
- **联通上海**：推出多档 Token 产品及融合套餐

## 为什么这件事值得关注

三大运营商 2025 年营收增速均低于 1%，传统语音和流量业务进入存量博弈时代。AI 产业链里，算力制造是阿里云/腾讯云的主场，运营商参与感极弱。Token 套餐是它们尝试切入 AI 变现的关键动作。

**运营商的逻辑：成为 AI 时代的"电商平台"**

知乎用户 @南天野望 的分析很到位：运营商想借助"巨无霸集采"能力，低价买入 AI 服务，集中卖给客户，扮演平台角色——就像淘宝对生产商一样拥有集采溢价。这条路在理论上成立，但有一个前提：AI 服务市场需要进入百模混战格局，平台才有议价空间；如果最后只剩两三家大模型，平台就没戏。

## 普通用户需要买吗？

高赞回答直接说：**不需要**。

- 现有的免费 AI（豆包、通义、Kimi）完全满足普通用户需求
- 运营商的 Token 量远不够正经开发者使用（一天烧多少 Token 他们知道吗？）
- 真正的开发者不会选运营商渠道——选生态、选文档、选 SDK，没人为了话费便利去买这个
- 最可能的用途：B 端企业走账，或者政府/国企 AI 采购走合规通道

**有意思的异见**：也有用户提到 20 元/月 coding plan 这类细分套餐的价值，运营商平台在定向补贴场景下可能偶有机会。

## 我的判断

这波套餐更像是"完成政治任务 + 占位"，而非真正为用户创造价值。运营商的核心优势是网络基础设施和 B 端客户关系，但 AI 消费的底层逻辑是"谁的模型好用就用谁"，跟手机号绑定是反直觉的。

真正的风险在于：如果上面施压，给运营商 AI 套餐一定的垄断特权（比如某类政企场景要求从运营商采购），那这个模式才有机会落地。市场化竞争下，可能性不大。

**对技术人的实际建议**：忽略个人版，定期关注企业版是否有定向优惠——假如某个模型通过运营商渠道提供超低价，值得薅一把。
