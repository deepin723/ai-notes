## 怎么理解这组结果

均线策略相对“买入后一直持有”少亏了约 27.6 个百分点，说明降低暴露确实缓冲了下跌；但它本身仍然亏损 27.58%，最大回撤也达到 37.56%，Sharpe 和 Profit Factor 都明显偏弱。因此，这次回测不能被解释成一个明确的买入信号。

RAM 是每日 2 倍杠杆 ETF，长期收益并不等于标的累计涨跌的简单两倍。高波动、每日再平衡和路径依赖会造成波动损耗；同时 RAM 上市历史较短，这次样本只有一个多月，结果很容易被少数极端交易日主导。

## 接下来重点观察

- 不只看当日涨幅，继续观察高开后能否守住 VWAP、开盘价和前高
- 记录成交量是否与突破同步，避免只看价格曲线
- 将回测区间、参数和交易成本作为同一套实验保存，避免只挑表现最好的参数
- 增加 RAM 对应底层资产或 DRAM 行业基准的对照，区分行业上涨与杠杆产品自身效应
- 全仓集中于 2 倍杠杆产品时，优先定义最大可承受回撤和退出条件
