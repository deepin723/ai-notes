## 项目是什么

[God's Eye View](https://github.com/bilawalsidhu/gods-eye-view) 是一个运行在浏览器里的开源空间情报工作台：在摄影级 3D 地球上叠加飞机、船舶、卫星、地震、交通和公开摄像头，并允许用实时语音代理控制视角。它今天在 GitHub Trending 获得约 1,984 Star。

它真正解决的不是“再做一个地图”，而是公开情报的界面碎片化。ADS-B、AIS、轨道根数、地震台网和摄像头本来散落在许多网页里；项目把它们统一成地点、时间和对象三种可组合语义。分享链接还能序列化相机、图层和当前跟踪对象，让一次观察成为可复现的交接。

## 技术与边界

项目要求 Node.js 24.14/26，核心入口是浏览器客户端；Google Photorealistic 3D Tiles 提供地球底图，部分私钥请求由本地 Vite 中间层代理，避免长期密钥进入浏览器。README 对实时、延迟、模拟、重建和不可用状态做显式标记，这是数据产品里非常稀缺的“认识论 UI”。

但“开源代码”不等于“所有数据都可商业使用”。项目的 DATA_SOURCES 明确区分 Google 专有条款、CC BY、非商业数据和第三方 3D 模型授权；历史回放也比实时展示昂贵得多，因为要持续存储、切片和索引时空数据。

## 我的判断

它的价值不只在炫酷，而在证明复杂信息系统可以把证据等级直接设计进界面。相比给用户一个“确定答案”，它持续显示数据来源、鲜度和模拟状态，能抑制把推演误认成事实。

最大风险同样来自视觉说服力：3D 地球与“作战室”风格会让不完整数据显得比实际更权威。项目禁止人物搜索、人脸识别和安全关键用途是必要边界，但部署者仍需限制滥用、保护 API Key，并逐项审查数据许可。

## 对我的启示

做自己的 3D 装机实验室或知识图谱时，可以借鉴三点：状态可分享、证据可追溯、模拟与真实必须视觉区分。漂亮不是终点，能让用户知道“这东西凭什么可信”才是成熟产品。
