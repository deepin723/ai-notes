# 先说结论

《荒野夜巡》现在的问题，不是枪手少了 10% 伤害，也不是剑客少了一个华丽大招，而是战斗还没有形成一条完整、可读、能不断产生选择的链路：

> 玩家意图 → 动作预备 → 命中确认 → 伤害与韧性结算 → 僵尸反应 → 视听反馈 → 恢复与下一次选择

目前的代码其实已经有不错的起点：枪手有标记、击退和跳弹，剑客有“荒魂出鞘”、本体锚点、伤害储存与强制归体，角色和怪物也有独立动作时钟。真正值得做的是用枪手、剑客和少量僵尸类型打磨一个战斗垂直切片，再扩展内容。

# 调研口径：拒绝用小样本污染玩法判断

核心样本必须同时满足四条：

1. 2024—2026 年发布过 1.0 或实质性战斗更新；
2. 有足够市场认知度，或来自成熟动作游戏团队；
3. 与俯视角动作肉鸽、auto-shooter 或英雄动作肉鸽直接相关；
4. 关键结论能由开发者官网、官方商店或官方更新验证。

因此核心池只保留：

- **Hades II v1.0（2025）**：观察武器形态、法术、Guardian 和角色叙事如何一起构成战斗身份；
- **Windblown 0.9.x（2026）**：观察高速动作、dash cancel、攻击恢复、敌人可读性和受击特效强度设置；
- **Death Must Die Act 3—4（2025—2026）**：观察祝福池稀释、跨系协同和主动/半自动/自动技能分支；
- **Deep Rock Galactic: Survivor 1.0（2025）**：观察 auto-shooter 如何用采矿、地形和任务目标打破绕圈杀怪；
- **Ravenswatch 1.2+（2025）**：观察英雄核心动词、专属天赋与 Boss 模式变化；
- **SWORN 1.0（2025）**：观察角色动作包与单局祝福层如何分工。

Dead Cells 只作为动作制作方法论；Yone 是剑客气质与结构参照；《星尘战线》是角色呈现和浏览器技术专项。VibeHub 普通小作品、不明来源数值和无一手证据的总结，不进入平衡数据集。

# 枪手方案：从自动射击器变成“六响处决者”

## 核心循环

枪手应保留自动瞄准，避免突然变成需要持续点射的双摇杆射击游戏，但自动攻击内部要有清晰节拍：

1. 六发弹仓自动射击；
2. 前五发稳定输出、叠标记、推开普通僵尸；
3. 第六发“定音弹”拥有更明显后坐，穿透一名普通敌人并优先兑现满层标记；
4. 玩家可以主动快速装填，舍弃余弹换取一次短侧移、移动加成或下一发更快拔枪。

这样每一梭都会自然形成“铺标记—选目标—末弹兑现—装填换位”的小循环。主动键提供的是节拍重置与脱困，不是又一个纯伤害按钮。

## 数值起点

- 保留现有约 44.5 的理论 DPS 作为第一轮基准，不同时提高射速和单发伤害；
- 普通弹 1.0 倍，定音弹暂定 1.35—1.55 倍，装填 0.75—0.95 秒；
- 标记维持两层，第二层优先改变弹道、穿透或控制，而不是继续堆倍率；
- 跳弹默认最多一次，伤害衰减到 65%—75%；第二跳只属于路线升级；
- 锁定目标保留 0.6—0.9 秒黏着，减少枪口在尸群间无意义乱摆。

## 三条行为成长路线

- **猎印**：定音弹命中满层标记后穿透，并把一层标记传给后方敌人；
- **快手**：剩余 1—3 发时主动装填，根据舍弃弹数获得短位移或下一发加速；
- **灵铳**：肩部灵体只复刻最后一次有效命中，不复制所有弹丸，避免特效和 DPS 一起失控。

# 剑客方案：西部魔影气质下的“穿阵归魂”

这里借鉴的是“双刀分工、灵体冒险、强制返回”的设计语法，不复制现成英雄的技能名称、动作、美术或数值。

## 双刀必须拥有不同职责

- **铁刃**：快、窄、短位移，负责点杀奔袭者和积累“势”；
- **魂刃**：慢、宽、韧性伤害高，能把普通僵尸扫向攻击弧末端，对精英只造成短顿挫；
- 两类命中累计两层“风痕”后，下一次铁刃变成短距离穿阵斩。

层数只能通过实际命中获得，挥空不能白送位移。穿阵斩的价值是开路和重新排列尸群：普通怪被侧推或短挑空，精英损失韧性，Boss 只增加破绽。它的基础伤害不应超过约 1.5 次普通攻击，否则位移、控制和伤害会同时超模。

## 重构“荒魂出鞘”

- 本体留在原地成为风险锚点；灵体获得移速和穿怪能力，但不是完全无敌；
- 灵体伤害留下“魂债”，归体时兑现部分储存伤害；普通、精英、Boss 使用不同生命百分比上限；
- 时间结束、再次按键或本体遇险都会强制沿路线归体；
- 归返线拉扯普通僵尸、削减精英韧性，对 Boss 只积累破绽；
- 同一敌群的魂债只结算一次，并通过依次收束的视觉节拍表现，避免一帧清屏。

这个技能真正有趣的地方，应该是“本体放在哪里、灵体走哪条路线、标记谁、什么时候回来”，而不是按下技能后全屏秒杀。

## 可以延后的第二主动

“断魄横斩”可以是一记宽弧防守斩：命中越多，短时护盾越高但有上限；能切掉小型敌方投射物，并打断抓取型僵尸的前摇。它承担空间管理，不与离魂争夺伤害定位。

现阶段不建议制作完整大招。先验证基础刀、穿阵斩和离魂循环，再把终结技作为路线最终升级。

# 僵尸必须成为玩法对象

| 敌人 | 受击与抵抗 | 枪手互动 | 剑客互动 |
|---|---|---|---|
| 游荡者 | 全额硬直、击退和挑空 | 作为标记传递与跳弹踏板 | 扫群、拉线和重排 |
| 奔袭者 | 冲刺前摇可被打断 | 提前点杀或定音弹截停 | 铁刃截击、穿阵反穿 |
| 披甲者 | 未破甲时只冒火花并轻微顿挫 | 连续锁定同一目标破甲 | 魂刃造成高韧性伤害 |
| 抓取者 | 抓取有明显手臂前摇，抓空后暴露 | 快速装填换位后打弱点 | 横斩断招或离魂诱导 |
| 精英 | 有韧性条，同类控制连续使用会衰减 | 把定音弹留给破韧窗口 | 在归返路线上完成破韧 |
| Boss | 不吃拉拽与挑空，招式后摇进入破绽 | 稳定命中打开弱点 | 用穿阵规避，归体兑现破绽 |

普通怪应该让玩家爽快地改变其位置；精英要求管理韧性；Boss 通过读招和破绽窗口提供高阶互动。不能用“所有怪都免控”解决平衡问题。

# 动画和动作设计

每个攻击都必须具备四段：**预备 → 释放/有效 → 命中确认 → 恢复**。伤害事件绑定释放或碰撞帧，不能由绘制帧顺带触发。

枪手一枪建议从 0.40—0.48 秒起调：

- 预备 90—120 ms：肩线收紧，枪口压低后抬起；
- 释放 1 帧：同时生成弹丸、枪焰和弹壳事件；
- 后坐 70—100 ms：上身和持枪手回弹，脚底不滑；
- 恢复 170—220 ms：枪口回线，释放后约 60% 进度允许移动或闪避取消。

剑客轻刀建议 0.32—0.40 秒，魂刃重斩 0.55—0.70 秒。轻刀靠方向改变和清脆音色确认，重刀靠更深预备、更宽残影、33—50 ms 的关键命中停顿与敌人位移确认。

所有时间只是本项目的起调范围，最终必须以 0.25× 和 1× 两档逐帧验收，检查脚底、接触帧、预备、释放和恢复是否清楚。

# 攻击反馈与受击反馈

反馈要变成可复用“配方”，而不是在武器和实体代码里到处直接累加震屏。

| 事件 | 画面与动作 | 时间/镜头 | 声音 |
|---|---|---|---|
| 轻弹命中肉身 | 小型方向火花、短血雾、肩部偏转 | 不停顿，极轻局部冲量 | 短促中高频穿肉声 |
| 弹中护甲 | 扁平白黄火花、无血、只轻顿 | 不震屏 | 金属钝响 |
| 定音弹/满标记 | 双层弹道、标记向命中点收束 | 16—33 ms 停顿，小幅定向震动并节流 | 低频枪响加确认音 |
| 铁刃 | 窄弧残影、敌人沿斩击方向扭转 | 通常不停顿 | 干净、短、明亮 |
| 魂刃/破韧 | 宽弧冷色残影、碎裂线、跪顿 | 33—50 ms，轻微镜头冲量 | 低沉切割与裂响 |
| 击杀 | 命中反馈后进入独立死亡层 | 重击/精英 50—67 ms；普通群杀合并 | 按肉身/护甲分组并限制并发 |
| 玩家受击 | 红边、清晰受击轮廓和保护性动作 | 镜头反馈高于普通攻击命中 | 低频告警并瞬时压低环境音 |

持续伤害和散弹不能让每一段都触发全局 hitstop。同一 50—80 ms 窗口内的多段命中需要合并反馈。

# 工程改造：先补战斗中枢

```text
输入 / 自动战斗
      ↓
ActionTimeline（预备、释放、有效、恢复、取消窗口）
      ↓ release 事件
碰撞检测 → HitTicket
      ↓
伤害 + 护甲 + PoiseController
      ↓
ReactionProfile（普通 / 精英 / Boss / 披甲）
      ↓
FeedbackBus（特效、声音、震动、停顿、数字；统一节流与合并）
```

- `ActionTimeline`：动作阶段和事件帧的唯一来源；
- `HitTicket`：携带伤害、来源、标签、冲量、韧性伤害、停顿级别和反馈 ID；
- `PoiseController`：处理破韧、恢复、控制衰减和 Boss 免疫；
- `ReactionProfile`：由敌人体型、材质和等级声明反应，武器不再写大量敌人特判；
- `FeedbackBus`：统一闪白、声音、震动、伤害数字、hitstop 和特效池。

现有 `combatmotion.js` 和 `monsteranimation.js` 可以保留。`main.js`、`entities.js`、`weapons.js` 中散落的反馈调用逐步迁入总线，不需要一次推翻全部代码。

# 《星尘战线》角色贴图与“乙游感”

公开运行页面能请求到 16 张透明 WebP：1 张指挥官和 15 张驾驶员立绘。抽样尺寸大约在 933×1400 到 1173×1341。代码将单张图片绘制进 Canvas，没有发现 Live2D、Spine 或角色逐帧动画。

看起来“会动”，主要来自角色周围的扫描线、粒子、光晕、HUD 动画和轻微构图变化，而不是角色图本身。它的角色感还依赖档案文案、台词、职业色盘和战斗头像的一致性。

这些图片技术上可以被浏览器下载，但作品页没有给出清晰的角色美术复用许可。公开送达客户端不等于允许复制、改编或再分发，因此不应把原图合进《荒野夜巡》或 AIHub。

更适合本项目的安全方案是：

- 枪手制作原创雨夜霓虹立绘，用呼吸、枪带摆动、雨滴遮罩三层轻视差；
- 剑客制作原创西部暗影立绘，用帽檐、魂火轮廓和尘烟层表达离魂；
- 每人先做一张透明主立绘和三个局部运动层，不急着制作昂贵的完整 Live2D 或全身逐帧动画。

# 最推荐的实施顺序

## Phase 0：建立可测量的战斗实验室

- 提供 0.25×、0.5×、1× 速度切换；
- 显示动作阶段、命中框、释放帧与韧性；
- 记录命中率、有效 DPS、过量伤害、受击来源和控制覆盖率；
- 固定随机种子，建立枪手和剑客各三分钟的对照回放。

## Phase 1：只做一个反馈垂直切片

1. 统一 `HitTicket`、`ReactionProfile` 与最小 `FeedbackBus`；
2. 加入枪手第六发“定音弹”；
3. 做出剑客铁刃/魂刃两种明确命中质感；
4. 只接入游荡者、披甲者和精英三种敌人；
5. 完成肉身、护甲、破韧、击杀四套反馈配方。

切片成立后，再进入韧性与控制衰减、枪手三条路线、剑客穿阵归魂和原创角色立绘。若这一小段仍不好玩，就应该继续改基础链路，而不是堆更多技能和角色。

# 验收标准

- 每次伤害只在释放/碰撞事件触发一次，绘制帧不会重复命中；
- 不看数字也能分辨肉身、护甲、破韧、暴击和击杀；
- 普通、精英、Boss 对同一技能的反应明显不同，但规则一致；
- 100 名敌人压力场景下，hitstop 不累积失控，特效池不无限增长；
- 震屏可调或关闭，低画质仍保留关键命中提示；
- 枪手形成约 3—5 秒一轮的弹仓节拍；
- 剑客离魂有清晰的进场、冒险和归返决策；
- 所有动作都通过 0.25× 与 1× 播放验收。
