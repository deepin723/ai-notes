## 为什么指数基金是普通人的最优解

**核心数据：** 过去20年，90%以上的主动基金长期跑输同类指数基金（美国市场数据）。

原因：
1. 主动基金费率高（1-2%/年），指数基金费率极低（0.05-0.5%）
2. 基金经理频繁交易，交易成本蚕食收益
3. 很难持续选中能持续跑赢市场的基金经理

巴菲特遗嘱：90%资产买标普500指数基金，10%买短期国债。

## ETF vs 普通指数基金

| 对比项 | ETF | 普通指数基金 |
|-------|-----|------------|
| 交易方式 | 实时交易（像股票）| 每日收盘后按净值申赎 |
| 最低投入 | 1手（通常100元起）| 通常10-100元起 |
| 费率 | 略低 | 略高 |
| 定投便利性 | 需手动操作 | 可设自动扣款 |
| 适合人群 | 主动择时者 | 长期定投者 |

## 中国市场主要指数选择

**宽基指数（首选）：**
- **沪深300**：A股最大的300家公司，代表中国核心资产
- **中证500**：中等市值500家，成长性更好，波动更大
- **中证全指**：覆盖A股95%市值，终极分散
- **纳斯达克100（QDII）**：投资美国科技龙头，汇率风险

**行业指数（卫星仓位）：**
- 消费（白酒/食品）：中证消费，长期稳健
- 医疗：中证医疗，人口老龄化受益
- 科技：中证科技，高波动高潜力
- 红利：中证红利，高股息，防守型

## 定投策略：时间平滑成本

定投（Dollar-Cost Averaging）：每月固定金额买入，不择时。

**优势：**
- 价格低时自动买入更多份额
- 消除择时的心理负担
- 强制储蓄，培养投资习惯

**定投增强策略（估值定投）：**
- PE低时（低估）：双倍定投
- PE正常：正常定投
- PE高时（高估）：减半定投或暂停
- 根据中证估值网等工具判断估值区间

**定投常见陷阱：**
- 熊市坚持不住停止定投（恰好在最佳买点退出）
- 以为定投一定赚钱（震荡下行市也会亏）
- 频繁换基金，产生额外成本

## 费率的复利杀伤力

假设投资100万，年化收益10%，30年：
- 年费0.05%（ETF）：最终约1720万
- 年费1.5%（主动基金）：最终约1250万
- **差距470万，仅因为费率**

选基金准则：**同类产品，费率最低的往往是最好的选择。**

## 实操建议

1. 优先选规模大（>50亿）、成立时间长、跟踪误差小的指数基金
2. 场内ETF选择流动性好的（日均成交额>1亿）
3. 支付宝/天天基金等平台有免申购费的指数基金
4. 每年做一次再平衡，维持目标仓位
5. 持有3年以上，方能体现复利效果
