## 微软的核心逻辑

市场担心 AI 会蚕食微软的传统产品（Office、Windows），但现实恰恰相反：

1. **AI 正在强化微软的护城河**：M365 Copilot 把原有订阅客户的单用户价值大幅提升，而不是被替代
2. **$627B 云订单积压**：这是锁定的未来营收，不是预测值。几乎相当于微软两年的总营收
3. **AI 业务 $37B 年化 + 123% 增速**：在微软这个体量（年收入约 $2500亿）上，单业务 $37B 且以 123% 增长，是罕见的组合
4. **所有华尔街分析师的目标价都高于当前股价**：这种共识性低估并不常见

---

## 英伟达的核心逻辑

多空最大分歧是：ASIC 自研（谷歌的 TPU、亚马逊的 Trainium、Tesla 的 D1）会不会颠覆 NVIDIA GPU 需求。

文章的反驳逻辑：
1. **Alphabet 最新表态**：$80B 股权融资专门为 AI 投资，今年 $180-190B capex，且 2027 年还要"显著增加"——这意味着 GPU 需求未见顶
2. **GPU vs ASIC 并非零和**：Alphabet、Amazon、Tesla 均公开表示会**同时**购买 Nvidia GPU 和自研芯片
3. **新增长曲线——Vera CPU**：Agentic AI 让 CPU 需求暴增，Nvidia 的 Vera CPU 有望今年贡献 $20B，对应 $2000亿 可寻址市场

---

## 我的判断

这两只股票被华尔街"共识性低估"的现象本身就值得深思。

**微软**的低估有其合理性：$385 的股价对应市盈率并不低（约 30-35x），但问题是市场在给微软的 AI 业务的定价方式。如果按照 SaaS 的高增速业务来估值（$37B AI 业务，123% 增速），这块业务单独就值几千亿。而市场似乎还在按"传统软件巨头"的框架给 MSFT 估值。

**英伟达**的逻辑有一个关键测试点：ASIC 自研的渗透率。如果谷歌 TPU 和亚马逊 Trainium 真的能在 2026-2027 年的 AI 推理端大规模替代 Nvidia GPU，$301 的目标价就高估了。但如果 agentic AI 时代 CPU 需求真的如 Nvidia 预测般爆发，$200B CPU 市场就是一个全新的主线逻辑。

**一个被忽视的数字**：Alphabet 的 $80B 股权融资专门为 AI——这是今年最大的资本行动之一，几乎无人在讨论它对英伟达订单的直接含义。

---

## 实际可用的结论

- MSFT 和 NVDA 是目前 Mag 7 里华尔街最看好（上行空间最大）的两个标的
- $627B 的 Azure 积压订单是微软最硬的护城河数据，值得记住
- NVDA 的 Vera CPU 是今年剩余时间最值得跟踪的新叙事
- 关注时间节点：Alphabet Q2 2026 财报（约 7 月底）会更新 capex 数字，是验证 GPU 需求逻辑的关键数据
