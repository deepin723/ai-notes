## 发生了什么

OpenAI 在 8 月 25 日披露首款自研推理芯片 Jalapeño 的测量结果，并把它放进从数据中心、芯片、模型、开发平台到终端设备的全栈战略。官方称，在 InferenceX 的 GPT-OSS 120B 测试中，它在对比系统里实现更高的单位功率峰值吞吐和更低 token 延迟，并在 DeepSeek R1、Kimi K2 上表现良好。

## 核心逻辑

自研芯片不是单纯替代 NVIDIA。推理工作负载相对稳定后，模型公司可以把内存、互联、调度和数值格式针对自己的流量共同优化。更低的每 token 成本会降低产品价格、扩大调用量，再产生更多真实负载数据，反过来指导下一代芯片与模型，这是一条垂直整合飞轮。

官方还强调“每美元有用智能”而不是裸算力：更好的路由、上下文管理和模型效率能减少重试。对于代理任务，完成一次工作可能要多轮工具调用，单 token 便宜但失败率高并没有商业价值。

## 我的判断

Jalapeño 的方向重要，但现有披露仍是厂商自选基准。峰值吞吐、延迟与能效不等于全生命周期成本；还要看良率、软件迁移、利用率、网络与内存瓶颈、故障恢复以及真实混合流量。

对 NVIDIA 而言，威胁不是客户立刻停止购买 GPU，而是大型客户把稳定推理迁向自研 ASIC，使通用 GPU 更多承担训练、前沿模型和突发需求。市场可能继续扩张，同时利润池在芯片、云和模型之间重新分配。

## 对我的启示

研究 AI 基础设施不能只盯 GPU 出货量。更好的监测框架是：训练与推理占比、单位成功任务成本、芯片利用率、内存/互联开销，以及自研芯片能否跨模型稳定运行。
